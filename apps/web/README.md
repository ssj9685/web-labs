# Web Labs App

The deployed Web Labs frontend. The current surface is Chess Access Lab: a
Three.js-rendered chess playground with imported 3D chess assets, selected-piece
aura effects, legal move markers, View Transition Toolkit capability checks,
typed move transitions, and a persistent DOM accessibility layer for keyboard
and screen reader play.

```bash
npm run dev -w @web-labs/web
npm test -w @web-labs/web
npm run build -w @web-labs/web
```
